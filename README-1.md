# AskMe AI

A simple AI chatbot web app. Chat UI in plain HTML/CSS/JS, backend in Node.js + Express. The API key stays on the server and is never exposed to the browser.

## Features
- Chat interface with message history
- Customisable system prompt (default: real estate assistant)
- Loading indicator and error messages
- Clear chat button

## Tech stack
Node.js, Express, HTML, CSS, JavaScript, Claude API

## Run locally
1. Clone the repo and run `npm install`
2. Copy `.env.example` to `.env` and add your API key
3. Run `npm start`
4. Open http://localhost:3000

## Deploy (Render)
1. Create a new Web Service from this repo
2. Build command: `npm install`, start command: `npm start`
3. Add environment variable `ANTHROPIC_API_KEY`
4. Deploy and add your live link here
